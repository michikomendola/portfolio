Teradyne Business Objects

Internal QA · report accuracy, UAT, SQL with TOAD for Oracle

Business Objects reports are only useful if the numbers match the warehouse. At Teradyne I tested BI outputs the way an analyst would use them, then proved the data with SQL.

Checks I ran

  • Functional and UAT testing of Business Objects solutions.
  • SQL queries in TOAD for Oracle to validate report totals, filters, and joins.
  • Test cases and scripts for recurring report packs.
  • Collaboration with report authors when a figure could not be reconciled.

Sample validation idea

SELECT region, SUM(net_amount) AS total
FROM finance.invoice_fact
WHERE invoice_date BETWEEN DATE '2023-01-01' AND DATE '2023-01-31'
GROUP BY region
ORDER BY region;

Compare each row to the BO table. A mismatch is a defect, even if the UI “looks fine.”
